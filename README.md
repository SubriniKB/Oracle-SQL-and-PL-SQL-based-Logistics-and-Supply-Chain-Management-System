# Oracle Logistics Management System

## Project Overview

The Oracle Logistics Management System is a database-driven application designed to manage logistics and supply chain operations.

The system manages the complete shipment lifecycle, including customer orders, shipment tracking, warehouse operations, vehicle assignment, driver management, route planning, payments, and reporting.

This project is developed to demonstrate practical skills in Oracle Database, SQL, PL/SQL, ETL concepts, and database performance optimization.

# Database Design

## Main Entities

The database consists of the following major entities:

| Entity | Description |
|---|---|
| CUSTOMER | Stores customer details |
| ORDERS | Stores shipment orders |
| SHIPMENT | Stores shipment information |
| SHIPMENT_STATUS_HISTORY | Tracks shipment lifecycle |
| WAREHOUSE | Stores warehouse information |
| INVENTORY | Maintains product stock |
| PRODUCT | Stores product details |
| VEHICLE | Stores vehicle information |
| DRIVER | Stores driver details |
| ROUTE | Stores delivery routes |
| PAYMENT | Stores payment details |
| INVOICE | Stores invoice information |
